# ServiceNow & DevOps Portfolio

## Overview
This repository is a learning and project portfolio focused on ServiceNow IT Service Management (ITSM), DevOps fundamentals, CI/CD workflows, and cloud operations.

The objective is to develop practical skills through documented examples, hands-on exercises, and progressively built projects.

## Areas of Focus
- **ServiceNow:** Incident Management, Problem Management, Change Management, and ITSM workflows.
- **DevOps:** Git, version control, CI/CD concepts, and deployment workflows.
- **Cloud Operations:** Infrastructure fundamentals, monitoring, and troubleshooting.
- **Technical Documentation:** Workflow diagrams, implementation notes, and project learnings.
